# 山大异闻 · 封藏之城

以山东大学校园为灵感的方块微缩风格动作角色扮演游戏。五个关卡、三种特色配装，以及简单／困难／地狱三档难度。

本仓库只存放可运行的网页构建和发布说明，不包含完整开发源码、内部测试资料、个人存档或凭据。浏览器必须下载的 JavaScript、CSS 等运行文件是公开的。

## 在线体验

[打开在线试玩](https://episodes202.github.io/sdu-sealed-city/)

首次游玩建议从主菜单选择“首次体验”。默认困难沿用原版难度，可以主动选择简单。

- [独立新手体验](https://episodes202.github.io/sdu-sealed-city/?trial=firstplay&difficulty=easy)
- [配装流派试玩](https://episodes202.github.io/sdu-sealed-city/?trial=builds)
- [最终Boss试玩](https://episodes202.github.io/sdu-sealed-city/?trial=final)

支持电脑端新版 Edge / Chrome。点击游戏页面后开始操作；游戏声音会在用户交互后启用。画面卡顿时，在暂停菜单选择“流畅”。混合光追依赖设备与浏览器能力，并非所有电脑都适合。

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD | 移动 |
| 鼠标左键 / J | 轻击 |
| 空格 / L | 按住蓄力，松开重击 |
| Shift | 翻滚闪避 |
| 鼠标右键 / K | 连弩，主线中解锁 |
| Q / R | 护腕技能，主线中解锁 |
| F | 药剂 |
| E | 交互 |
| Tab | 装备 |
| Esc | 暂停 |

战斗外可切换配装。连击强调续段与快速收尾，破甲强调持势定向重斩，游击强调弩箭标记与近战后的接射。

## Windows 免安装版

请在 [Releases](https://github.com/Episodes202/sdu-sealed-city/releases/latest) 下载 Windows ZIP，完整解压后双击“启动游戏.cmd”。包内已包含 Node.js 运行环境，无需另行安装；不要直接双击网页文件，也不要在压缩包内运行启动器。

进度保存在当前浏览器的本地存储中。在线试玩与本地免安装版的地址不同，因此存档不会自动互通。首次体验、配装和终战试玩不覆盖正常主线进度。
